# Generalised workspace model

## Problem Framing

The framework needed a coherent task-focused workspace, reliable continuation and a portable skill distribution path. Duplicated instructions and legacy contribution handling created maintenance and disclosure risks.

## Approach

Prepared concise instructions, a source map, task handoffs and a self-contained reviewed skill bundle. Implemented preview-first local setup and diagnostics, tested representative success/failure paths and checked an isolated package archive.

## Key Decisions

Preserved existing files on conflict and kept connectors, accounts, hooks and model execution outside automatic setup. Consolidated duplicated skill templates, replaced ungrounded examples and removed tracked outreach from the proposed tree without claiming to erase history.

## Outcome

Prepared the workspace model, migration guidance and fictional example for review. Local tests, skill validation, bundle checks and packaging checks pass; no package release, visibility change or merge is implied. Automatic extraction could not locate this task, so this sanitized contribution record was prepared manually from the visible conversation.
