Read the operating model

Preview before applying

From a framework source checkout, create a small local workspace with the starter selection.

node plugin/bin/workspace.js init ../my-product --runtime codex
node plugin/bin/workspace.js init ../my-product --runtime codex --apply
node plugin/bin/workspace.js doctor ../my-product
node plugin/bin/workspace.js start ../my-product --focus "Review a product request"

Initialization and diagnostics do not call a model, start services, configure connectors or edit global settings. Add --apply to a launch preview only when you want to start the independently installed agent.

Choose the starter, product or evidence selection, or named skills. Required references and scripts travel with the reviewed bundle. Private sources and accounts stay in the target environment.

Review changes without losing local policy

node plugin/bin/workspace.js compare /path/to/workspace

The read-only report separates local edits, upstream changes and conflicts, with installed/local/proposed text and review patches. It never applies updates. Reports can contain private local text and should remain private.

Diagnostics report candidate instructions and source configuration; they do not certify the runtime's actual discovery, authentication or current business facts.
