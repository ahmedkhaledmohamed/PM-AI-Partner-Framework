# Workspace quick reference

| Intent | Request |
| --- | --- |
| Start | Read workspace context, then focus on the named task. Done when the stated result is reviewable. |
| Resume | Read the named task document's handoff, verify current sources and continue the next approved action. |
| Investigate | State the question, scope and authoritative sources. Separate implemented, enabled, observed and measured claims. |
| Plan | Compare requested changes with current support. Keep proposals, routine support, discovery and commitments distinct. |
| Consolidate | Identify who owns each fact. Preserve decisions and source identities; derive views from maintained records. |
| Review | Challenge the evidence, scope and consequential failure paths. Report unresolved limits. |
| Finish | Verify the actual output, deliver the review link and update the existing handoff. |

Preview workspace setup and launch with the [local CLI](../../getting-started.md). Check [source ownership](workspace-operating-model.md) before synchronizing artifacts. Follow the target environment's approval policy; this reference grants no sending, publishing or merge authority.
