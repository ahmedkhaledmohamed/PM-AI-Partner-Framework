# Task prompts

Use a prompt that names the work, output and completion condition. These prompts do not grant permission to send, publish, push or merge beyond the target policy.

## Start

> Read workspace context, then focus on [task]. Done when [observable result]. Read only the relevant sources and flag material freshness limits.

## Resume

> Resume [task] from [working document or review]. Recover the accepted decisions, verify current sources and continue the next approved action.

## Investigate

> Check [claim] within [scope]. Separate approved intent, inspected implementation, rollout and measured outcomes. Show the evidence and what remains unresolved.

## Plan

> Reconcile [requests and unfinished work] for [period]. Show current versus proposed job definitions, genuine delivery homes, shared dependencies and independently reviewable decisions. Preserve existing scope choices.

## Consolidate

> Review these artifacts for the reader's task. Identify which source owns each fact, propose trimming that preserves meaning, and show how linked views stay consistent.

## Verify impact

> Assess [change] using defined cohorts, denominators and primary results. Distinguish measured outcomes from assumptions and forecasts. Check whether historical effects apply to the proposed population.

## Finish

> Verify the requested output and summarize what changed, why, how it was checked and the material limits. Update the existing task handoff with remaining work and next action.
