# PM AI Partner Framework

The maintained [workspace operating model](workspace-operating-model.md) describes task context, source authority, planning, execution, artifacts and continuation. Start with [getting started](../../getting-started.md) for a small local workspace.

Use [workflow guides](workflows/README.md) for a specific task, [the fictional example](../examples/workspace-task.md) to see the relationships, and [migration](workspace-migration.md) for an existing setup. Skills are procedures selected for the task, not personalities that must be invoked for every request. A meaningful completion condition and verified output matter more than following a fixed document sequence.
