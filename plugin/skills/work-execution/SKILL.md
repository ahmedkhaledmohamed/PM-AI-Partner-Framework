# Execute an agreed task

Use for sustained work with an agreed goal, plan and completion condition. A short edit does not require this workflow.

Recover the latest accepted plan, decisions and current worktree/review. State what is already done and the next useful action. Preserve scope corrections across sessions; a new status request does not cancel the underlying task.

Execute coherent chunks with observable outputs. Reuse existing sources and patterns; do not add a new work item because a related initiative or speculative capability exists. Complete work that is already authorized before asking for the next decision. Ask only for missing information, an actual policy gate or a material choice; identify what caused a required approval.

Keep implementation permission, external writes, publishing, pushing and merging distinct under the target environment's policy. Prepare the full reviewable diff and required contribution record together before an exact-diff checkpoint; a plan approval is not approval of a later diff. Another agent's review cannot confer human approval. Check the effective account and remote before external actions. Respect exact-diff gates when present; never assume one merge approval covers later reviews.

Verify the consequential behavior using the relevant existing checks or representative outputs. For formatted artifacts, verify actual layout and content placement; counts and matching words alone do not establish correctness. Broaden verification only to resolve a concrete remaining risk or satisfy a required gate.

Record implementation state separately from tracker state, deployment and measured outcome. Human review, an inaccessible source, an unconfirmed rollout or an unresolved owner decision may be an accepted terminal condition only when the user agrees. Label it explicitly; do not invent certainty or continue an endless loop to avoid a review handoff.

At completion, report what changed, why, evidence of verification, material limits and review links. Update the existing task handoff with remaining work and the next action. Do not call a task complete solely because a document or checklist exists, and do not claim an in-session loop continues after the session ends.
